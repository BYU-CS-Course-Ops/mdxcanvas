# Release Checklist

Use this page after source validation and before a live deployment.

- Confirm the target is a dedicated sandbox.
- Run with `--dry-run` and inspect create, update, delete, and untrack actions.
- Deploy and inspect pages, assignments, quizzes, modules, files, links, diagrams, and slides.
- Deploy unchanged source again and expect no content changes.
- Verify no generated artifacts were added to Git.
