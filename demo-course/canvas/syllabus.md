# MDXCanvas Integration Course

This mini-course exists to verify MDXCanvas rendering and deployment before a release.

## Workflow

1. Run a dry run against a dedicated sandbox.
2. Review planned changes and warnings.
3. Deploy, then inspect every module and resource type in Canvas.
4. Repeat the same deployment to verify idempotence.
5. Make one controlled edit and verify the update plan.
