# MDXCanvas skill migration audit and disposition record

## Scope and decisions

This record supersedes the provisional flat-layout plan and scratch audit. There are **25** legacy `skill.md` files, not 24. Each real Markdown heading outside fenced examples has a row below; child sections account for their own content rather than being hidden in file-level conclusions. Meaningful content without headings is included under its containing heading. Destinations refer to exact current packaged files/headings. Runtime evidence was inspected, not assumed from `documents/`; cited tests are evidence of intent, **not a claim they were executed**.

User decisions: full tag references belong in `mdxcanvas/skills/tags/`; Content Author renders `{{ myteam_list('tags/') }}`. Authoring requirements match parser behavior, including optional content-backed module-item IDs. The five public skill paths remain. A dedicated root Jinja reference completes operational templating coverage. No managed workflows are inferred from legacy procedural guides. The user explicitly waived focused parser/runtime checks for final migration; this waiver supersedes the original removal gate requiring them.

## Reconciled contradictions

- Explicit IDs are required for assignments/pages/quizzes/questions/modules/generated Markdown pages. Module item IDs derive from content_id for page/assignment/quiz/file; subheader/externalurl/syllabus item IDs are required. Previous claims that all items require explicit IDs are rejected.
- Assignment/quiz group references use declared stable group IDs, not names. Group categories and assignment grading groups remain distinct.
- Announcement publish_date is declared required but its truthy parsing-time default wins before required checks. Omission works; explicit dates are appropriate for deterministic scheduling. The earlier audit's blanket required-publish_date conclusion was incorrect.
- Quiz attempts default to emitted -1; falsy shuffle default is omitted. Explicit false disables shuffling; omission does not reset existing Canvas state.
- Active deployment does not call the legacy date-localization helper. Parser ISO normalization is not UTC conversion. File locks bypass parse_date. late_due is forwarded, not an independently enforced cutoff.
- Helper fenced is boolean, not a language. md-page title uses the first line, not an arbitrary later heading. Current include/data helper path scopes and asset identity derivations are documented.
- Questions cover all 12 parser types, aliases and feedback, current file-upload points, matching override behavior, positional multiple-tf identities, and numerical prompt-answer leakage. Classroom choices are not parser mandates.
- Non-secret course-info is committed and includes DEPLOY_ROOT; tokens remain external. Runtime ignores arbitrary top-level branding keys unless source consumes them.
- Deprecated course rhythms, fixed grading percentages, automatic publication, rigid scaffold/naming requirements, and recursive loaders are not preserved as policy.
